# Mi Curriculum Vitae Profesional
¡Bienvenida a mi proyecto de CV interactivo! Este sitio web fue desarrollado como proyecto para el Bootcamp de **Kibernum (2025-2026)**. 
Es un currículum completamente responsivo que combina diseño moderno, accesibilidad y dinamismo a través de la manipulación del DOM.

## Características Clave 
**Diseño 100% Responsivo:** Adaptado perfectamente para celulares, tablets y computadoras utilizando el sistema de grillas de **Bootstrap 5**.
**Modo Oscuro Dinámico:** Botón interactivo que alterna el esquema de colores de la página (`light-mode` / `dark-mode`) de manera fluida mediante JavaScript y CSS nativo.
**Formulario de Contacto Validado:** Validación interactiva en tiempo real con eventos `change` y `submit`. Informa al usuario si los campos cumplen con los requisitos 
mínimos y despliega una alerta de éxito temporal.
**Tipografía Personalizada:** Integración de Google Fonts.

## Tecnologías utilizadas
**HTML5:** Estructura semántica del sitio.
**CSS3:** Estilos personalizados, transiciones suaves y variables de color para los modos.
**Bootstrap v5.3.3:** Maquetación, componentes de navegación, tarjetas y utilidades de espaciado.
**JavaScript (ES6):** Manejo de eventos en el formulario y cambios de tema 
**Git & GitHub:** Control de versiones del proyecto.
